# Hábitos Sustentáveis
### Conscientização, implementação e gerenciamento de hábitos sustentáveis ao meio ambiente

Projeto interdisciplinar do curso de Ciência da Computação da Universidade Paulista (UNIP), com foco na implementação de hábitos sustentáveis utilizando princípios da psicologia comportamental, neurociência, economia comportamental e interação humano-computador.
